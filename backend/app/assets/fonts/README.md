# Bundled PDF fonts

DejaVu Sans 2.37, including regular, bold, oblique and bold-oblique faces, is
bundled for consistent PDF exports with Cyrillic support on every operating system.

Source: [DejaVu Fonts 2.37 release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).
The files are unmodified; redistribution terms are in `LICENSE-DejaVu.txt`.

`EXPORT_PDF_FONT_PATH` can override the regular TrueType font path. Companion
faces named with `-Bold`, `-Oblique` and `-BoldOblique` suffixes are discovered
automatically alongside it.
